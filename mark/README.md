# mark

`[●]™`: thin black square brackets, an orange dot (signal, `#ff5000`), a small superscript ™.

- `mark-pixel-57x27.png` is the master: the exact pixel mark from the iPod, transparent background. `@2x`/`@4x`/`@8x` are nearest-neighbour copies, so they stay sharp.
- `mark.svg` is a vector redraw for print and large sizes.
- Place it top right, inset 8 from the top and 16 from the right (at 1x), in the **same spot on every screen** of a set.
- The dot is never recoloured. The ™ appears only here.
